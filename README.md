# Do Zero ao Site

Landing page de um webinar gratuito para quem quer publicar a primeira página
com HTML, CSS e JavaScript. Projeto acadêmico dos exercícios 4 e 5.

**Site publicado:** https://rebecca-ads.github.io/landing-page/

## Funcionalidades

- Cabeçalho com nome do projeto, slogan e botão de chamada para ação
- Formulário de inscrição com nome, e-mail, CEP e mensagem
- Validação dos campos e mensagem de agradecimento ao enviar
- Consulta de endereço pela API ViaCEP, que preenche rua, bairro, cidade e UF
- Layout responsivo, com paleta em verde, menta e coral

## Tecnologias

- HTML5
- CSS3
- JavaScript (fetch e manipulação do DOM)
- API [ViaCEP](https://viacep.com.br/)
- Git e GitHub Pages

## Como rodar

1. Clone o repositório:
   `git clone https://github.com/Rebecca-ADS/landing-page.git`
2. Abra o arquivo `index.html` no navegador.

## Organização das branches

- `main`: versão estável, publicada no GitHub Pages
- `develop`: desenvolvimento e testes
